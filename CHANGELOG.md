# Changelog

Notable user-facing changes are recorded here. Versions use Semantic Versioning.

## [0.1.0] - 2026-10-01

### Added

- Responsive React PWA and Fastify service with clearly labelled demo mode.
- Pianoteq preset switching and master-volume control through the JSON-RPC adapter.
- Audio connection information and clearly unsupported audio/MIDI selectors.
- Editable, locally saved appearance presets with colour contrast feedback.
- Shared runtime-validated contracts and a Vitest regression suite.
